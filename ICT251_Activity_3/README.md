# ICT251 Activity 3 — Interactive Personal Website

## About the Project
This project is a personal website created using HTML, CSS, and JavaScript. It presents my personal information, hobbies, learning plan, photographs, media, projects, and contact details.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Interactive Features
- Light and dark theme switch
- Project search and filtering
- Expandable content
- Contact form validation and message preview

## How to View
Open `index.html` in a web browser or visit the deployed website using its Render link.

## Folder Structure
- `index.html` — Main webpage
- `css/` — Stylesheet files
- `js/` — JavaScript files
- `Images/` — Photographs
- `videos/` — Video and audio media
